## Configura el acceso

En **Configuración → Integraciones**, solicita a un administrador que cree una integración con los permisos necesarios y genere una API key. Guarda la key cuando se muestre: solo puedes verla una vez.

Define `LUMOS_API_BASE_URL` con la URL base confirmada para tu entorno, incluyendo `/integrations/v1`. Define `LUMOS_API_KEY` con la credencial guardada en tu gestor de secretos.

## Consulta cuentas

Necesitas el permiso `accounts:read`. La key identifica a tu empresa; no envíes `tenantId` ni `x-tenant-id`.

```bash
curl --get "$LUMOS_API_BASE_URL/accounts"   --data-urlencode 'limit=50'   --header "x-api-key: $LUMOS_API_KEY"
```

La respuesta contiene `data` y `nextCursor`. Si hay otro cursor, úsalo para obtener la página siguiente.

## Crea una cuenta

Necesitas `accounts:write`. Usa una clave de idempotencia distinta para cada operación y conserva la misma al reintentar.

```bash
curl --request POST "$LUMOS_API_BASE_URL/accounts"   --header "x-api-key: $LUMOS_API_KEY"   --header 'Content-Type: application/json'   --header 'Idempotency-Key: 542296f4-cf53-4e8c-85c4-8a749c5f0a11'   --data '{"name":"ACME Perú","country":"PE","status":"active"}'
```

Tu empresa puede exigir campos adicionales. Consulta el [catálogo de campos personalizados](/api-reference/endpoint/custom-fields-list) y las reglas configuradas antes de crear registros.
