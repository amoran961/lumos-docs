## URL base

El contrato define `https://platform.lumosai.biz/integrations/v1` como servidor predeterminado. Confirma el host y cualquier prefijo de gateway con tu administrador para el entorno que vas a utilizar.

## Operaciones disponibles

| Recurso | Operaciones |
| --- | --- |
| Cuentas, contactos y oportunidades | Listar, obtener, crear y actualizar parcialmente |
| Actividades | Listar, obtener y registrar |
| Tareas | Listar, obtener, crear y actualizar; completar mediante `status=completed` |
| Pipelines | Consultar pipelines y etapas |
| Usuarios | Consultar usuarios para asignaciones |
| Campos personalizados | Consultar claves, tipos y opciones por entidad |

Las actualizaciones usan `PATCH`. La API pública v1 no expone eliminación de registros.

Las escrituras respetan los campos obligatorios y las reglas de negocio del CRM. Las referencias a cuentas, contactos, usuarios y etapas deben pertenecer a tu empresa.

## Contrato OpenAPI

Descarga el [contrato OpenAPI](/api-reference/openapi.json) para consultar esquemas y generar clientes. La referencia de endpoints utiliza ese mismo archivo.

## Compatibilidad

Esta documentación describe el módulo nuevo de API pública v1. La integración anterior también usa `/integrations/v1`, pero tiene autenticación y operaciones diferentes. Confirma que v1 está habilitada antes de migrar. Las operaciones internas de correo y la administración de credenciales no forman parte de esta referencia pública.
